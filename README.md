# mcu_controller

Прошивка для микроконтроллера К1874ВЕ7Т. Она обрабатывает команды и обновляет телеметрию по МКО, а также обрабатывает запросы RMAP по SpaceWire.

## Сборка и запуск через MSYS

1. Подключите эмулятор памяти к компьютеру и узнайте номер его COM-порта в диспетчере устройств Windows.
2. Убедитесь, что в MSYS доступны `make`, инструменты CodeMaster CMC‑96 (`mcc96` и `mclink`) и команда `python`. Укажите каталоги заголовков и библиотек CMC‑96 в переменных `CMC96_INCLUDE` и `CMC96_LIB`. Если PySerial ещё не установлен, выполните `python -m pip install pyserial`.
3. В MSYS перейдите в каталог с `Makefile` и запустите сборку с загрузкой прошивки:

   ```bash
   cd "/c/Projects/mcu_controller/mcu mko"
   make build_sw COM=COM5
   ```

   Замените путь на свой, а `COM5` — на порт эмулятора. Команда собирает прошивку, преобразует HEX-файл в `bin/cmc96/main.bin` и передаёт его в эмулятор памяти. По умолчанию используется 16-битная шина. Для 8-битной добавьте `BUS=8`.

Чтобы загрузить уже собранный образ, выполните `make load_sw COM=COM5`.

## Основные функции

| Файл | Функции |
| --- | --- |
| `main.c` | `main` инициализирует таймер, UART, SpaceWire и терминал МКО, затем обрабатывает события в основном цикле. `timer_irq_handler` обновляет буферы телеметрии, `build_mko_status` формирует слово состояния МКО, а `bsi_rt_irq_handler` обрабатывает события терминала. |
| `bsi_rt.c` | `init_bsi_terminal` и `bsi_data_init` настраивают терминал МКО и его буферы. `bsi_tx` читает данные из буфера передачи, а `bsi_rx` записывает данные в буфер приёма. `AD_to_BSI` переносит данные из памяти AD в буфер передачи МКО, а `BSI_to_AD` переносит принятые данные в память AD. |
| `packet_process.c` | `handle_mko_packet` выбирает обработчик по подадресу. `handle_dpu` обрабатывает команды ДПУ, `handle_VD_option_2` готовит данные для выдачи по запросу, а `handle_config_packet` проверяет CRC-8 и идентификатор модуля перед записью конфигурации. `update_scc` обновляет счётчик и историю кодов команд. |
| `spacewire.c` | `SpW_Init` настраивает SpaceWire. `IRQ_SpW_handler` вызывает `SpW_Get_Bytes` для чтения принятых байтов. `SpW_Send_Packet` передаёт пакет, а `SpW_erase_fifo` очищает приёмный FIFO. |
| `RMAP_ctrl.c` | `parser_RMAP` разбирает и проверяет запрос, `build_rmap_reply` формирует ответ, а `SpW_RMAP_target` связывает обработку запроса с приёмом и передачей по SpaceWire. |
| `tools/cmc96/mcu_loader.py` | `main` управляет последовательностью загрузки образа в эмулятор памяти через COM-порт. `send_cmd` отправляет служебные команды, а `send_data` передаёт длину и содержимое образа. |
